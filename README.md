# splat-host-mobile

Phone packages of the TH OWL Campus Viewer scans (one folder per scan, same
paths as in `splat-host`). Each package holds the coarsest level of the original
scan plus three thinned levels (50 / 25 / 12.5 %). The viewer loads them only on
phones; desktops keep using `splat-host`.

Built with `@playcanvas/splat-transform` 3.11 (SOG v2).
